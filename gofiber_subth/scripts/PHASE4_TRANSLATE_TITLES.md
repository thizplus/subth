# Phase 4: แปล Video Titles เป็นภาษาไทย (สไตล์คำคล้องจอง)

## 🎨 สไตล์การแปล: คำคล้องจอง (Rhyming Thai)

### รูปแบบ
```
[CODE] ซับไทย [คำคล้องจอง 4-8 คำ] [ชื่อนักแสดง EN]
```

### ลักษณะเด่น
1. **คล้องจอง** - มีสัมผัสในตัว เช่น "ว้าวุ่น-คลั่งลุง", "ย่องเบา-แอบพ่อ"
2. **กระชับ** - 4-8 คำไทย ไม่ยาวเยิ่นเย้อ
3. **สื่อความหมาย** - บอกเนื้อเรื่องแบบไม่ตรงตัว
4. **ติดหู** - อ่านแล้วจำได้ ไม่แห้งแล้ง
5. **ศัพท์แสลง** - ใช้คำแสลงไทยได้ เช่น "ดุ้น", "เงี่ยน", "ซอย"

## 📋 Prompt Design (สำหรับ Gemini)

```
คุณคือนักเขียนก๊อปปี้ไทยที่เชี่ยวชาญการตั้งชื่อแบบ "คำคล้องจอง" - สั้น กระชับ ติดหู มีสัมผัส

**งาน**: แปลชื่อวิดีโอเป็นภาษาไทยในสไตล์คำคล้องจอง

**รูปแบบ output**:
[CODE] ซับไทย [คำคล้องจอง 4-8 คำ] [ชื่อนักแสดง EN]

**กฎ**:
1. คำคล้องจองต้องมีสัมผัส (เสียงคล้ายกัน) เช่น "ว้าวุ่น-คลั่งลุง", "แอบพ่อ-ย่องเบา"
2. ใช้ 4-8 คำไทย - กระชับ ไม่ยืดยาว
3. สื่อเนื้อเรื่องแบบอ้อมๆ ไม่ตรงตัว
4. ใช้คำแสลงได้ เช่น "ดุ้น", "เงี่ยน", "ซอย", "ตอก"
5. ใช้ auto_tags ช่วยเสริมบริบท (ไม่ต้องใส่ทุกอัน)

**ตัวอย่าง**:
- "Drunk wife forgot husband" → "เมาลืมเมียอ่อนเพลียกลางวงสวิง"
- "Niece visits uncle" → "หลานสาวว้าวุ่นวัยรุ่นคลั่งลุง"
- "Secret affair behind house" → "หลังบ้านต้องแอบพ่อแสบย่องเบา"
- "Boss and stressed relationship" → "หัวหน้าแก้คันสัมพันธ์ตึงเครียด"
- "Mother-in-law and son-in-law" → "ลูกเขยรอบจัดกำหนัดแม่ยาย"
- "Brothers and sisters bond" → "พี่น้องคู่เงียบเสียบกระชับสัมพันธ์"

**ข้อมูล video**:
[
  {
    "code": "SSNI-963",
    "title": "Japan's No. 1 SEX Cosplayer Yua Mikami",
    "cast": "Yua Mikami",
    "auto_tags": ["cosplay", "big_breasts", "slim"]

**ตอบเป็น JSON เท่านั้น**:
{"SSNI-963": "SSNI-963 ซับไทย คอสเพลย์เยอร์เบอร์หนึ่งเมืองปลาดิบ Yua Mikami"}
```

## ⚙️ Script Flow

```
1. Query videos ที่ยังไม่มี title TH (จาก video_translations)
   │
2. สำหรับแต่ละ batch (20 videos):
   │
   ├─ ดึง code, title, auto_tags, cast
   ├─ สร้าง prompt พร้อม few-shot examples
   │
3. ส่งไป Gemini 2.0 Flash API
   │
4. Parse JSON response
   │
5. INSERT/UPDATE video_translations (lang='th')
   │
6. Sleep 1s (rate limit) → Next batch
   │
7. Save checkpoint ทุก 100 batches
```
