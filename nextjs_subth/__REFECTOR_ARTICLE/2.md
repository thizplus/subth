3️⃣ PROMPT ใหม่ (นี่คือหัวใจ)

Prompt เดิมคุณ = AI เขียนบทความ

Prompt ใหม่ = AI เขียน “หน้า SEO”

🔥 PROMPT สำหรับ generate บทความ (ใช้ได้จริง)

เอาไปใช้ได้เลย:

🎯 PROMPT
You are writing a review article designed to rank in search engines.

Your goal is NOT to write an essay.
Your goal is to answer search intent fast, clearly, and usefully.

Follow this structure strictly:

1. Write a short verdict first (2 sentences max)
2. Write a quick summary (3 sentences max)
3. Write a factual info block (actors, studio, genre, length)
4. Write a story overview (short, no fluff)
5. Write analysis sections:
   - Acting
   - Visual style
   - Pacing
6. Write pros and cons as bullet points
7. End with a clear recommendation:
   Who should watch / who should skip

Rules:
- Avoid generic phrases like “this movie presents” or “it explores themes”
- Use direct, natural tone
- Avoid repeating the same ideas
- Each paragraph must add new information
- Prefer clarity over length
🎯 PROMPT สำหรับ tone human มากขึ้น
Write like a critic explaining to a friend,
not like a film student writing an essay.

Avoid academic tone.
Avoid over-dramatic words.
Be practical and specific.
