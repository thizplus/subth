## 🎯 Implementation Requirements

### 1. ข้อมูลที่ดึงได้จาก Database (10 fields)
- videoCode, videoId, thumbnail, videoDuration
- releaseDate, castIds, makerId, tagIds, categoryIds
- viewCount

### 2. ข้อมูลที่ต้อง Query/Calculate (10 fields)
- previousWorks → Query videos by same cast
- relatedBySameCast → Query videos by cast
- relatedBySameMaker → Query videos by maker
- keywords → Map from AutoTags
- gallery → Parse from GalleryPath
- translationMethod → Map from Subtitle.Type
- subtitleQuality → Map from Subtitle.Confidence
- relatedVideoIds → Combine cast/maker/tag queries
- readingTime → Calculate from summary word count
- title → Format from VideoTranslation

### 3. ข้อมูลที่ต้องกรอก Manual (13 fields)
- slug (auto-suggest from videoCode)
- ratingOverall, ratingStory, ratingDialogue, ratingPerformance
- translationNote (template)
- technicalFaq (template)
- ttsEnabled, ttsVoiceId
- likeCount (future feature)
- audioUrl, audioDuration, ttsStatus (TTS Worker)

### 4. ข้อมูลที่ต้องใช้ AI สร้าง (28 fields) ⭐
**Input สำหรับ AI:**
1. **SRT File** (Subtitle content) → สำคัญที่สุด!
2. Video metadata (code, duration, cast, maker, tags)
3. Previous works ของ cast คนเดียวกัน

**AI จะสร้าง:**
- metaTitle, metaDescription, thumbnailAlt
- highlights (Timeline), sceneLocations
- dialogueAnalysis, characterInsight, topQuotes
- languageNotes, actorPerformanceTrend, comparisonNote
- summary, summaryShort, characterDynamic
- plotAnalysis, recommendation, recommendedFor
- thematicKeywords, settingDescription, moodTone
- faq, longTailKeywords
- audioContent (สำหรับ TTS)
- embedding (Vector)

## 🚨 Critical Dependencies

### 1. SRT File (Subtitle) - จำเป็นมาก!
```
Location: api.suekk.com → subtitles.srt_path
Format: S3 path → subtitles/{video_code}/th.srt
```
**AI ต้องอ่าน SRT เพื่อ:**
- สกัด topQuotes (ประโยคเด็ด)
- วิเคราะห์ dialogueAnalysis
- หา thematicKeywords (สถานที่, บริบท)
- สร้าง highlights (จาก timestamp)

### 2. Gallery Images
```
Location: api.suekk.com → videos.gallery_path
Format: S3 path prefix → gallery/{video_code}/
Count: videos.gallery_count (0-100 ภาพ)
```
**ต้อง:**
- List images from S3 path
- Auto-generate alt text สำหรับแต่ละภาพ

### 3. Cast Previous Works
```
Query: SELECT * FROM videos
       WHERE casts @> '{cast_id}'
       AND id != current_video_id
       ORDER BY release_date DESC
       LIMIT 5
```
**ใช้สำหรับ:**
- actorPerformanceTrend
- comparisonNote
- previousWorks array

2. เป็น public API สำหรับ frontend

**แต่ต้อง:**
- เรียก API ไป api.suekk.com เพื่อดึง:
  - SRT content (Subtitle)

## 🔄 Data Flow for Article Generation

```
┌─────────────────────────────────────────────────────────────┐
│                    Article Generation Flow                   │
└─────────────────────────────────────────────────────────────┘

1. Admin เลือก Video จาก api.subth.com
   │
   ▼
2. System ดึงข้อมูลจาก api.suekk.com
   ├── GET /subtitles/{code}/th.srt  → SRT content
   ├── GET /videos/{code}/gallery    → Gallery images
   └── GET /videos/{code}            → Duration, quality
   │
   ▼
3. System ดึง Previous Works
   └── Query videos by same cast (api.subth.com)
   │
   ▼
4. ส่งทุกอย่างไป Gemini AI
   │
   ▼
5. AI สร้าง E-E-A-T content (28 fields)
   │
   ▼
6. Admin review & edit
   │
   ▼
7. Save Article + Generate TTS (ElevenLabs)
   │
   ▼
8. Generate Embedding (OpenAI/Gemini)
   │
   ▼
9. Publish
```
